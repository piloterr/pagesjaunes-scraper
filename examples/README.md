# PagesJaunes Scraper API – code examples

Examples for every PagesJaunes endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/page_info.sh`](curl/page_info.sh) | `bash page_info.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/page_info.php`](php/page_info.php) | `php page_info.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/PageInfo.cs`](csharp/PageInfo.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/page_info.go`](go/page_info.go) | `go run page_info.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/PageInfoExample.java`](java/PageInfoExample.java) | `java PageInfoExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/page_info.rb`](ruby/page_info.rb) | `ruby page_info.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/page_info.mjs`](nodejs/page_info.mjs) | `node page_info.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
